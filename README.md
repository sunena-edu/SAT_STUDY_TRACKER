# SAT STUDY TRACKER
beginner python SAT study tracker for recording and analysing study progress and practice test scores

# Features

# Study Tracking
record daily study hours,
log subjects studied,
store topics covered, 
saves studied dates for progress tracking, 
# Practice Test Tracking
record SAT practice test dates,  
store practice test scores, 
maintain score history, 
# Performance Analysis
compare latest score with previous scores, 
identify the highest score achieved,  
monitor score improvement overtime, 

# Technology Used 
Python/ Pydroid 3
